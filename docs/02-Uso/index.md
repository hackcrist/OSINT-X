## Flujo de Trabajo

```
Menú 01-09 → objetivo → resultado estructurado en pantalla
09 REPORT → formato (json/txt/html) → carpeta de reportes
```

El menú Python sale con `00`; el atajo Shell acepta módulo y objetivo en una línea.
