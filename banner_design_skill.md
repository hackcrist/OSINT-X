# Banner Design Skill — Visual Excellence

## 1. Propósito

Esta skill define las reglas para diseñar banners visualmente sobresalientes, profesionales y coherentes con el objetivo del proyecto.

La prioridad no es llenar el espacio de elementos, sino construir una composición visual clara, atractiva, memorable y técnicamente correcta.

El resultado debe sentirse diseñado por un profesional de dirección de arte y diseño gráfico, no como una plantilla genérica.

---

## 2. Regla principal

Cada banner debe responder claramente a estas preguntas antes de diseñarse:

1. ¿Qué se está comunicando?
2. ¿A quién está dirigido?
3. ¿Cuál es el mensaje principal?
4. ¿Qué acción o reacción se espera?
5. ¿Dónde se utilizará?
6. ¿Qué dimensiones y formato necesita?
7. ¿Qué identidad visual debe respetar?

Si falta información que pueda cambiar significativamente el resultado, preguntar antes de diseñar.

No inventar información de marca, promociones, precios, fechas, características, logotipos, nombres o textos.

---

## 3. Regla de generación

Esta skill NO debe generar una imagen automáticamente.

Solo debe generar un banner cuando el usuario lo solicite explícitamente.

Frases como:

- "crea el banner";
- "genera el banner";
- "hazme el diseño";
- "renderiza el banner";
- "quiero ver el banner";

constituyen una solicitud explícita.

Pedir ideas, analizar un diseño, definir una composición, crear un concepto o escribir especificaciones NO equivale a solicitar la generación de una imagen.

---

## 4. Descubrimiento antes del diseño

Antes de diseñar, determinar cuando sea necesario:

- objetivo;
- audiencia;
- marca;
- plataforma;
- dimensiones;
- orientación;
- mensaje;
- llamada a la acción;
- imágenes disponibles;
- logotipo;
- colores de marca;
- tipografías;
- restricciones;
- fecha o contexto de publicación.

Si el usuario ya proporcionó la información, no volver a preguntarla.

Si una información faltante no afecta materialmente al diseño, utilizar una solución profesional razonable y continuar.

Si sí puede cambiar el resultado de forma importante, preguntar.

---

## 5. Dirección de arte

Cada banner debe tener una dirección visual definida.

Antes de construir la composición, elegir conscientemente:

- estilo;
- jerarquía;
- ritmo visual;
- punto focal;
- tratamiento fotográfico o ilustrativo;
- sistema cromático;
- tratamiento tipográfico;
- densidad visual;
- profundidad;
- contraste;
- nivel de sofisticación.

No mezclar estilos incompatibles sin una razón de diseño.

Evitar diseños visualmente ruidosos cuando el objetivo requiere claridad.

---

## 6. Jerarquía visual

Todo banner debe tener una jerarquía claramente reconocible.

Orden recomendado:

1. Punto focal.
2. Mensaje principal.
3. Información secundaria.
4. Llamada a la acción.
5. Marca o información auxiliar.

El usuario debe poder identificar el mensaje principal rápidamente.

No permitir que:

- el logotipo domine innecesariamente;
- el texto secundario compita con el titular;
- demasiados elementos tengan la misma importancia;
- la llamada a la acción desaparezca;
- el fondo compita con el contenido.

---

## 7. Composición

La composición debe utilizar principios profesionales de diseño:

- alineación;
- proximidad;
- repetición;
- contraste;
- balance;
- escala;
- ritmo;
- espacio negativo;
- líneas de dirección;
- profundidad;
- tensión visual cuando sea intencional.

No centrar todos los elementos automáticamente.

No distribuir elementos de manera simétrica por defecto.

La asimetría puede utilizarse cuando produzca una composición más dinámica y controlada.

---

## 8. Punto focal

Cada banner debe tener un punto focal dominante.

El punto focal puede ser:

- una persona;
- un producto;
- una fotografía;
- una ilustración;
- una palabra;
- una cifra;
- una forma;
- una composición tipográfica.

Los demás elementos deben apoyar ese punto focal.

No crear múltiples puntos focales con igual intensidad sin una razón concreta.

---

## 9. Espacio negativo

El espacio vacío es un elemento de diseño.

No rellenar zonas simplemente porque estén vacías.

Utilizar espacio negativo para:

- separar grupos;
- mejorar legibilidad;
- dirigir la mirada;
- aumentar la percepción de calidad;
- dar protagonismo al mensaje;
- evitar saturación.

Un banner elegante no necesita estar lleno.

---

## 10. Tipografía

La tipografía debe ser funcional y expresiva.

Seleccionar tipografías de acuerdo con:

- personalidad de la marca;
- audiencia;
- contexto;
- legibilidad;
- idioma;
- tamaño;
- plataforma.

Evitar utilizar demasiadas familias tipográficas.

Regla general:

- una familia puede ser suficiente;
- dos familias pueden crear contraste;
- más de dos requiere una justificación clara.

Controlar:

- tamaño;
- peso;
- interlineado;
- tracking;
- ancho de línea;
- alineación;
- contraste;
- longitud del titular.

No deformar tipografías artificialmente.

No utilizar efectos tipográficos excesivos si reducen la calidad.

---

## 11. Texto

El texto debe ser:

- breve;
- claro;
- jerárquico;
- legible;
- correcto;
- visualmente integrado.

No modificar el significado del texto proporcionado por el usuario.

No inventar slogans.

No corregir información comercial sin autorización.

Si el texto es demasiado largo para un banner, advertirlo y proponer una versión condensada antes de sustituirlo.

---

## 12. Color

Construir una paleta intencional.

Considerar:

- color de marca;
- contraste;
- temperatura;
- saturación;
- psicología visual;
- legibilidad;
- contexto de publicación.

No utilizar colores aleatorios.

No usar gradientes únicamente porque sean visualmente llamativos.

Los gradientes, brillos, sombras y efectos deben tener una función visual.

Cuando el banner pertenezca a una marca existente, priorizar su identidad visual.

---

## 13. Contraste y legibilidad

Todo texto importante debe poder leerse rápidamente.

Verificar contraste entre:

- texto y fondo;
- botones y fondo;
- logotipo y fondo;
- elementos secundarios y entorno.

Evitar colocar texto directamente sobre zonas visualmente complejas sin tratamiento adecuado.

Se pueden utilizar:

- overlays;
- degradados;
- paneles;
- sombras sutiles;
- desenfoque de fondo;
- separación tonal;

cuando mejoren realmente la legibilidad.

---

## 14. Imágenes y elementos visuales

Cuando existan imágenes proporcionadas por el usuario:

- respetar su intención;
- evitar deformaciones;
- mantener proporciones;
- priorizar el sujeto principal;
- integrar iluminación y color;
- evitar recortes accidentales;
- comprobar zonas seguras para texto.

No sustituir una imagen proporcionada sin autorización.

No inventar elementos de marca.

---

## 15. Profundidad

La profundidad puede construirse mediante:

- escala;
- superposición;
- perspectiva;
- desenfoque;
- iluminación;
- sombras;
- contraste;
- separación de planos.

Los efectos deben utilizarse con moderación.

No agregar sombras, brillos, partículas, reflejos, humo o elementos decorativos simplemente para hacer que el diseño parezca más elaborado.

La sofisticación proviene de la composición, no de la cantidad de efectos.

---

## 16. Calidad fotográfica y visual

Cuando el diseño utilice fotografía o elementos realistas, priorizar:

- iluminación coherente;
- anatomía correcta;
- materiales creíbles;
- reflejos consistentes;
- perspectiva correcta;
- profundidad de campo natural;
- integración de bordes;
- escala coherente;
- ausencia de artefactos.

Evitar resultados que parezcan:

- stock genérico;
- collage accidental;
- composición artificial;
- imagen sobrecargada;
- publicidad genérica.

---

## 17. Identidad de marca

Si existe una identidad visual definida, respetar:

- logotipo;
- colores;
- tipografías;
- estilo fotográfico;
- tono;
- iconografía;
- espaciado;
- proporciones;
- elementos reconocibles.

No rediseñar una identidad existente durante la creación de un banner salvo que el usuario lo solicite.

---

## 18. Llamada a la acción

Cuando el banner tenga una acción prevista, la CTA debe ser:

- visible;
- breve;
- diferenciada;
- fácil de localizar;
- coherente con la jerarquía.

Ejemplos de estructura:

```text
Título
Información breve
[ Llamada a la acción ]
```

No convertir la CTA en el elemento visual dominante salvo que ese sea el objetivo.

---

## 19. Adaptación a plataformas

El diseño debe considerar el medio final.

Antes de entregar versiones para diferentes plataformas, comprobar:

- proporción;
- resolución;
- área segura;
- recortes automáticos;
- legibilidad en móvil;
- tamaño de texto;
- posición del logotipo;
- posición de la CTA.

No simplemente escalar el mismo banner cuando el cambio de proporción perjudique la composición.

Cuando sea necesario, realizar una adaptación específica por formato.

---

## 20. Sistema responsive para banners

Cuando un diseño deba existir en varias proporciones, conservar:

- identidad;
- jerarquía;
- mensaje;
- punto focal;
- estilo.

Pero permitir cambios de:

- posición;
- escala;
- recorte;
- alineación;
- espaciado;
- composición;
- tamaño tipográfico.

No forzar una única composición a todos los formatos.

---

## 21. Banners publicitarios

Para publicidad, priorizar:

1. Atención.
2. Comprensión.
3. Deseo o interés cuando corresponda.
4. Acción.

No sacrificar legibilidad por impacto.

Evitar afirmaciones comerciales inventadas.

No añadir precios, descuentos, porcentajes, fechas, garantías o beneficios que el usuario no haya proporcionado.

---

## 22. Banners corporativos

Para banners corporativos priorizar:

- claridad;
- autoridad visual;
- consistencia de marca;
- espacio;
- tipografía;
- orden;
- confianza.

Evitar recursos visuales excesivamente informales si no corresponden a la marca.

---

## 23. Banners promocionales

Para promociones, la jerarquía debe dejar claro:

- qué se ofrece;
- cuál es el beneficio;
- cuándo aplica, si corresponde;
- cómo actuar.

Los números importantes pueden utilizarse como elementos visuales fuertes, pero sin competir con la información esencial.

---

## 24. Banners de eventos

Priorizar:

- nombre del evento;
- fecha;
- lugar o plataforma;
- elemento visual principal;
- CTA cuando corresponda.

La información crítica debe permanecer legible incluso en tamaños reducidos.

---

## 25. Regla de no sobrecarga

No utilizar automáticamente:

- partículas;
- destellos;
- neón;
- glow;
- sombras fuertes;
- bordes;
- marcos;
- texturas;
- patrones;
- iconos;
- elementos 3D;
- efectos cinematográficos.

Cada elemento debe tener una función.

Si eliminar un elemento mejora la composición, eliminarlo.

---

## 26. Originalidad

Evitar diseños genéricos.

Buscar originalidad mediante:

- composición;
- tipografía;
- escala;
- dirección visual;
- fotografía;
- contraste;
- espacio;
- ritmo;
- tratamiento de marca.

No confundir originalidad con complejidad.

Un diseño minimalista puede ser más distintivo que uno recargado.

---

## 27. Precisión del contenido

El contenido proporcionado por el usuario debe preservarse con precisión.

No cambiar:

- números;
- precios;
- fechas;
- nombres;
- URLs;
- teléfonos;
- direcciones;
- nombres de productos;
- nombres comerciales;

sin autorización.

Si se detecta una posible inconsistencia, preguntar antes de corregirla.

---

## 28. Cambios no previstos

Si durante el diseño aparece una decisión que puede cambiar sustancialmente el resultado:

1. detenerse;
2. explicar la decisión;
3. presentar las alternativas relevantes;
4. preguntar al usuario.

No asumir preferencias de marca o dirección de arte cuando no exista suficiente información.

---

## 29. No hacer trabajo adicional

No crear automáticamente:

- variantes;
- formatos adicionales;
- versiones para redes;
- animaciones;
- mockups;
- logos;
- recursos gráficos;
- campañas completas;

si el usuario solicitó únicamente un banner.

Los extras se pueden proponer, pero no producir sin autorización.

---

## 30. Revisión visual obligatoria

Antes de considerar terminado un banner, comprobar:

- [ ] El mensaje principal se identifica rápidamente.
- [ ] Existe una jerarquía clara.
- [ ] El punto focal es evidente.
- [ ] El texto es legible.
- [ ] El contraste es suficiente.
- [ ] El espacio negativo está controlado.
- [ ] La composición está equilibrada.
- [ ] La marca está correctamente integrada.
- [ ] No hay elementos innecesarios.
- [ ] No existen errores de texto.
- [ ] No existen elementos deformados.
- [ ] No existen recortes accidentales.
- [ ] Los elementos importantes están dentro de zonas seguras.
- [ ] El diseño corresponde al formato solicitado.
- [ ] El resultado mantiene coherencia visual.
- [ ] No se inventó información.

---

## 31. Criterio de excelencia

Un banner excelente debe conseguir simultáneamente:

### Claridad

El usuario entiende qué está viendo.

### Impacto

Existe un punto visual capaz de captar atención.

### Jerarquía

Los ojos reciben la información en el orden correcto.

### Belleza

La composición es estética y deliberada.

### Legibilidad

El contenido funciona incluso en tamaños reducidos.

### Identidad

El diseño pertenece claramente a su marca o concepto.

### Memoria

Existe al menos un elemento visual distintivo que facilite recordarlo.

### Funcionalidad

El diseño cumple su objetivo, no solamente se ve bien.

---

## 32. Regla de belleza

No perseguir belleza mediante acumulación de elementos.

La belleza debe provenir principalmente de:

- proporción;
- equilibrio;
- contraste;
- tipografía;
- composición;
- color;
- ritmo;
- espacio negativo;
- coherencia;
- intención.

Cuando haya que elegir entre más elementos y una mejor composición, priorizar la composición.

---

## 33. Regla de dirección artística

No empezar colocando elementos.

Primero determinar:

```text
Objetivo
→ Mensaje
→ Audiencia
→ Punto focal
→ Jerarquía
→ Composición
→ Tipografía
→ Color
→ Elementos visuales
→ CTA
→ Formato
→ Revisión
```

---

## 34. Regla maestra

> Crear el banner más bello posible dentro del objetivo real del proyecto, no el banner más cargado de efectos.

El resultado debe parecer intencional, refinado, profesional y memorable.

Cada elemento debe justificar su existencia.

Si un elemento no mejora el mensaje, la composición, la identidad o la función del banner, no debe estar presente.


## 35. Identidad exclusiva del proyecto activo

La skill debe trabajar siempre con el proyecto que el usuario esté trabajando en ese momento.

El banner debe utilizar únicamente información perteneciente al proyecto activo, salvo que el usuario autorice expresamente reutilizar recursos externos.

No mezclar entre proyectos:

- nombres;
- logotipos;
- colores;
- tipografías;
- fotografías;
- slogans;
- productos;
- precios;
- datos;
- estilos;
- recursos gráficos;
- archivos;
- campañas;
- versiones.

Si existen recursos de varios proyectos disponibles, identificar primero cuáles pertenecen al proyecto activo.

Si no puede determinarse con seguridad a qué proyecto pertenece un recurso, preguntar antes de utilizarlo.

---

## 36. Nombre del banner

El nombre del banner debe derivarse del proyecto que se está trabajando.

No utilizar nombres genéricos como:

```text
banner_final.png
banner_nuevo.png
banner_1.png
diseño_final.png
final_final.png
```

Preferir una nomenclatura profesional basada en el proyecto.

Ejemplo:

```text
NombreProyecto_Banner_Principal
NombreProyecto_Banner_Promocional
NombreProyecto_Banner_Evento
```

Si el usuario solicita únicamente un banner y no proporciona un nombre específico para la pieza, utilizar el nombre del proyecto y un descriptor breve de la función del banner.

No inventar un nombre comercial para el proyecto.

---

## 37. Organización de recursos

Mantener una separación clara entre:

```text
Proyecto
├── Identidad
├── Recursos
├── Banners
├── Versiones
└── Exportaciones
```

La estructura exacta puede adaptarse al entorno disponible, pero la separación conceptual debe mantenerse.

Nunca mezclar automáticamente archivos de proyectos diferentes.

---

## 38. Contexto visual por proyecto

Cuando el proyecto ya tenga banners o recursos visuales existentes, utilizarlos como referencia para mantener continuidad.

Analizar, cuando estén disponibles:

- paleta;
- tipografía;
- composición;
- tratamiento fotográfico;
- estilo de botones;
- bordes;
- sombras;
- iconografía;
- proporciones;
- tono visual.

No cambiar la identidad visual del proyecto simplemente para hacer un banner individual más llamativo.

---

## 39. Registro mental del proyecto activo

Durante una misma tarea, mantener claramente separado:

```text
PROYECTO ACTIVO
Nombre:
Identidad:
Objetivo:
Banner solicitado:
Recursos autorizados:
Formato:
```

Este contexto debe utilizarse únicamente para la tarea actual.

No importar información de otros proyectos salvo autorización explícita.

---

## 40. No contaminación entre proyectos

Si el usuario cambia de proyecto, considerar el nuevo proyecto como un contexto independiente.

No reutilizar automáticamente:

- nombre;
- logo;
- colores;
- recursos;
- slogans;
- diseños;
- textos;
- archivos;

del proyecto anterior.

Si el usuario quiere mantener una línea visual entre proyectos diferentes, debe indicarlo.

---

## 41. Control de archivos

Antes de utilizar o sobrescribir un archivo, comprobar:

1. a qué proyecto pertenece;
2. qué tipo de recurso contiene;
3. si corresponde al banner actual;
4. si es una versión anterior;
5. si existe riesgo de sobrescribir un diseño válido.

No sobrescribir una versión existente sin autorización cuando pueda implicar pérdida de trabajo.

Cuando sea necesario crear una nueva versión, utilizar una nomenclatura clara.

Ejemplo:

```text
NombreProyecto_Banner_Principal_v01
NombreProyecto_Banner_Principal_v02
NombreProyecto_Banner_Principal_Final
```

No utilizar:

```text
final2
final_final
ahora_si_final
nuevo_final_bueno
```

---

## 42. Organización máxima

La prioridad de organización es:

```text
Proyecto correcto
→ Recursos correctos
→ Identidad correcta
→ Banner correcto
→ Formato correcto
→ Versión correcta
→ Exportación correcta
```

Antes de entregar, comprobar que el resultado pertenece al proyecto solicitado y no contiene información accidental de otro proyecto.

---

## 43. Regla de aislamiento

> Un banner pertenece a un solo proyecto.

Toda decisión visual, textual y de identidad debe derivarse del proyecto activo.

Si el usuario está trabajando en `Proyecto A`, la skill no debe producir un banner de `Proyecto B`, aunque existan recursos de ambos disponibles.

---

## 44. Regla de nombres y proyecto

Cuando el usuario diga:

> "Hazme un banner"

la skill debe determinar primero cuál es el proyecto activo.

Si el proyecto está claramente identificado, utilizar ese proyecto como referencia.

Si existen varios proyectos activos y no se puede determinar cuál corresponde, preguntar:

> "¿Para cuál proyecto quieres crear el banner?"

No elegir uno al azar.

---

## 45. Regla de limpieza

No crear copias innecesarias.

No duplicar recursos sin motivo.

No dejar archivos temporales como parte de la entrega final.

No mezclar borradores con entregables finales.

Mantener las versiones identificables y ordenadas.

---

## 46. Regla maestra de organización

> El usuario debe poder abrir la carpeta o conjunto de recursos y entender inmediatamente qué proyecto corresponde a cada banner, qué versión es cada archivo y cuál es el entregable final.

La organización forma parte de la calidad del diseño.

Un banner visualmente excelente pero mal organizado no se considera una entrega profesional.
